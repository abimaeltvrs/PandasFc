📢 Áudios próprios / avisos

Para manter o projeto gratuito, envie o MP3/M4A/OGG manualmente para a pasta audio/ no GitHub e cadastre abaixo o caminho ou URL. Ex.: audio/aviso-patrocinador.mp3.

ℹ️ Como funciona

Todos os usuários podem controlar Play/Pause, Anterior, Próxima e Volume no mini player do cabeçalho. Somente a DIRETORIA vê esta aba e consegue trocar a playlist ou cadastrar/remover avisos.

O botão 📢 Tocar para todos publica um aviso no Firebase. Usuários que estiverem com o PANDAS FC aberto receberão o aviso no player e, ao terminar, a playlist volta a tocar quando o navegador permitir.
