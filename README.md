# PANDAS FC

Versão estática pronta para GitHub Pages. Não usa React, Vite, npm ou GitHub Actions.

## Como publicar

1. Apague os arquivos antigos do repositório ou crie um repositório limpo.
2. Envie `index.html`, `styles.css` e `app.js` para a raiz do repositório.
3. Em **Settings > Pages**, escolha **Deploy from a branch**.
4. Selecione a branch **main** e a pasta **/(root)**.
5. Salve e aguarde a publicação.

O endereço será `https://SEU-USUARIO.github.io/NOME-DO-REPOSITORIO/`.

## Dados

Os jogadores, partidas, logo e estatísticas são salvos no `localStorage` do navegador/dispositivo.
