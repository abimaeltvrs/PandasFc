# PANDAS FC instalável

Esta versão transforma o site em PWA e adiciona um botão de instalação quando o navegador oferecer suporte.

Arquivos principais:
- index.html
- styles.css
- app.js
- manifest.webmanifest
- sw.js

No GitHub Pages, mantenha:
- Source: Deploy from a branch
- Branch: main
- Folder: /(root)

Depois de publicar, abra o site pelo Chrome no Android. Quando a instalação estiver disponível, o botão "Instalar aplicativo" aparecerá.
